# 프로젝트 전체 구상

> 계획서(정보과학 프로젝트) 내용을 바탕으로, 실제 구현 관점에서 정리한 문서.
> 진행하면서 계속 갱신한다.

## 1. 한 줄 정의

사용자가 관심 있는 선수·팀을 고르면 관련 이적설 기사를 모아 보여주되, 각 기사를 쓴
기자·매체가 얼마나 신뢰할 만한지 함께 표시해 주는 서비스.

## 2. 전체 아키텍처

```
1~5차시: Next.js 프론트만으로 완결된 서비스 (더미 데이터 배열 사용)
           ↓
6~8차시: Supabase(Postgres)를 붙여서 더미 데이터를 실제 DB 데이터로 교체
```

- **프레임워크**: Next.js (App Router) + TypeScript
  - 컴포넌트 단위로 화면을 쪼개서 만들기 쉽고, Vercel 배포가 매우 간단해서 5차시 목표(첫 배포)에 적합.
- **스타일**: Tailwind CSS — 클래스만으로 빠르게 UI를 만들 수 있어 매 차시 진도를 맞추기 좋음.
- **배포**: Vercel (5차시, 배포 완료).
- **DB**: Supabase — Postgres 기반, 테이블 설계가 계획서의 "저장할 데이터" 항목과
  1:1로 대응됨. 스키마는 [`supabase/schema.sql`](../supabase/schema.sql) 참고
  (6차시: 테이블 생성 + 클라이언트 연동. 아직 로그인 기능이 없어서 RLS는 꺼둔 상태 —
  자세한 이유는 schema.sql 상단 주석 참고).
- **상태 관리**: 별도 라이브러리 없이 React `useState` + props로 충분 (규모가 작음).

## 3. 데이터 모델 (계획서 2번 항목 기준)

3개 테이블. 3~5차시는 이 구조를 그대로 TypeScript 타입 + 더미 배열로 먼저 만들고,
6차시에 Supabase 테이블로 옮긴다.

### `journalists` (기자)

| 필드 | 설명 |
|---|---|
| id | PK |
| name | 기자 이름 |
| outlet | 소속 매체 |
| league_tiers | `{ league: string, score: number }[]` — 리그별 신뢰도 티어 점수 |
| base_tier | 기본 신뢰도 티어 점수 (담당 리그 기록이 없을 때 대신 사용) |

### `articles` (기사)

| 필드 | 설명 |
|---|---|
| id | PK |
| url | 원문 링크 |
| journalist_id | FK → journalists |
| player_name | 관련 선수명 |
| from_team / to_team | 이적 전 / 이적 후 팀 |
| certainty | 확실성 카테고리: `확정` \| `진전` \| `관심` |
| summary | 요약 코멘트 |
| published_at | 등록 날짜 |
| score | 계산된 개별 신뢰 점수 (파생값) |

### `rumors` (이적설)

| 필드 | 설명 |
|---|---|
| id | PK |
| player_name | 관련 선수명 |
| article_ids | 관련 기사 id 목록 |
| aggregate_score | 종합 신뢰 점수 (파생값) |
| updated_at | 최종 업데이트 날짜 |

### `players` (선수) — 계획서 원안엔 없던 4번째 테이블, 7차시 진행 중 추가

관리자 등록 폼에서 "선수를 검색해서 선택"하고, 선택하면 현재 소속팀으로
"이적 전 팀"을 자동으로 채우기 위해 추가했다. `articles.player_name`은 여전히
단순 텍스트 컬럼이라(관계형으로 바꾸지 않음) 이 테이블과 FK로 묶여있지 않다 —
순수하게 등록 폼의 입력 보조용.

| 필드 | 설명 |
|---|---|
| id | PK |
| name | 선수 이름 (unique) |
| current_team | 현재 소속팀 |

> 지금은 공식 10명만 들어있지만(`supabase/seed.sql`), 실제 배포할 때는 여기에
> 선수를 더 많이 추가하면 등록 폼의 검색-선택에 그대로 반영된다.

## 4. 신뢰도 계산 로직 (계획서 2번 "처리" 항목 기준)

1. 기사 등록 시 선수/팀/기자/날짜 기준으로 태그 부여.
2. `(기자, 기사에 태그된 리그)` 조합으로 `journalists.league_tiers`에서 티어 점수 조회.
   - 해당 리그 기록이 없으면 `base_tier` 사용.
3. `개별 기사 신뢰 점수 = 티어 점수 × 확실성 가중치`
   - 확실성 가중치(초기안, 조정 예정): `확정 = 1.0`, `진전 = 0.7`, `관심 = 0.4`
4. `종합 신뢰 점수 = 같은 이적설에 속한 기사들의 개별 점수 평균`
   - 1단계: 단순 평균으로 구현 (5차시 목표)
   - 2단계 개선: 최신 기사에 가중치를 더 주는 방식으로 발전 (계획서 5번 "대비 방법"과 동일)

이 계산 함수는 `lib/trustScore.ts`에 순수 함수로 작성해서, 더미 데이터든 실제 DB
데이터든 동일하게 재사용한다 (3~5차시는 더미 배열을 넣고, 8차시에 실제 DB 조회
결과를 넣기만 하면 되도록).

> **리그 태그 규칙**: 2번의 리그 태그는 "이적 전 소속팀(from_team)의 리그"를 기준으로
> 정한다. 예) AC 밀란(세리에 A) 선수가 첼시(프리미어리그)로 이적하는 기사는
> `league: 세리에 A`. 이렇게 해야 디 마르치오(세리에 A 전문)·플레텐베르크(분데스리가
> 전문) 같은 리그 특화 기자가 실제로 자기 전문 리그에서 높은 점수를 받는 사례와,
> 전문 리그가 아닐 때 기본 티어로 대체되는 사례를 둘 다 보여줄 수 있다.

## 5. 화면 구성

계획서 3번 스케치 기준, 핵심 화면 3개:

1. **메인 화면**: 검색창 + 왼쪽 사이드바(팀별/기자별/선수별 필터) + 이적설 카드 목록.
   - "최신순"은 항상 적용되는 기본 정렬이고, "팀별/기자별/선수별"은 사이드바에서
     구체적인 팀·기자·선수를 선택해 목록을 실제로 걸러내는 필터다(가나다순 재배열이 아님).
2. **상세 화면**: 특정 이적설의 관련 기사를 날짜순 타임라인으로 표시 (기자/매체/확실성/개별 점수/원문 링크).
3. **관리자 기사 등록 화면**: 기사 링크·기자 이름·관련 선수·관련 팀·확실도 입력 폼.

### 5-1. 카드 디자인 방향

- **왼쪽 사이드바 필터**: 상단 가로 버튼 대신 세로 사이드바에 "팀별/기자별/선수별"
  섹션을 두고, 각 섹션 안에 실제 선택지(팀 이름·기자 이름·선수 이름) 버튼을 나열한다.
  나중에 필터 종류가 늘어나도(리그 추가, 이적료 범위 등) 섹션만 추가하면 되는 구조.
- **출처 표기**: 카드 하단에 "1주 전 · 데이비드 오른스타인 ↗"처럼 상대 날짜 + 기자명 +
  링크 아이콘을 한 줄로 표시. 계획서의 "원문 링크" 요구사항과 그대로 대응된다.
- **팀 배지**: 실제 구단 로고 이미지 대신, 저작권 문제 없는 원형 이니셜 배지(TOT/MCI/MUN/LIV/CHE)로 스캔하기 쉽게 만든다.
- **화이트 배경 + 미니멀 타이포**: 색은 팀 배지에만 쓰고 나머지는 절제된 톤 유지.

## 7. 다룰 선수·팀 목록 (1차시 결과물)

더미 데이터(3차시)와 이후 화면 예시 전반에서 재사용할 기본 목록. 여러 리그를
넓게 다루는 대신 **프리미어리그, 그 중에서도 토트넘 관련 이적설**에 집중해서
범위를 좁혔다.

**팀 (5, 우선순위 순 — 토트넘이 최우선)**

1. 토트넘 홋스퍼
2. 맨체스터 시티
3. 맨체스터 유나이티드
4. 리버풀
5. 첼시

**선수 (5, 공식 목록)**

1. 오마르 마르무시 — 맨시티 → 토트넘
2. 사비뉴 — 맨시티 → 토트넘
3. 미하일로 무드릭 — 첼시 → 토트넘 (임대)
4. 루카 부슈코비치 — 브라이튼 → 토트넘
5. 코디 가크포 — 리버풀, 토트넘/맨시티가 영입 경쟁하는 구도

> **더미 데이터 확장 (3차시)**: 필터(팀별/기자별/선수별)를 제대로 테스트하려면
> 카드가 훨씬 많아야 해서, 위 5명 외에 5팀이 골고루 걸리도록 5건을 더 추가했다
> (`lib/dummyData.ts` 기준, 총 10건·25개 기사). 5개 핵심 팀은 그대로 유지하면서
> 상대 구단만 다양화(PSG·도르트문트·AC밀란·레알 마드리드·알-힐랄 등)했다.
>
> 6. 곤살로 라모스 — PSG → 맨체스터 유나이티드
> 7. 니코 슐로터베크 — 보루시아 도르트문트 → 리버풀
> 8. 라파엘 레앙 — AC 밀란 → 첼시
> 9. 브루누 페르난데스 — 맨체스터 유나이티드 → 알-힐랄 (아웃고잉)
> 10. 콜 파머 — 첼시 → 레알 마드리드 (아웃고잉)
>
> ⚠️ 위 10명·관련 이적설은 `lib/dummyData.ts`에만 있는 **더미(가상) 데이터**다.
> 8차시부터 화면은 더미 데이터를 안 쓰고 실제 Supabase DB만 보기 때문에,
> 지금은 화면에 안 뜬다 — 코드 참고용으로만 남아있다.

> **실제 데이터 확장 (7~8차시 이후, `supabase/seed.sql` / `seed_real_articles.sql`)**:
> `players` 테이블에 공식 10명 외에 실제로 존재하는 유명 선수 45명을 더
> 추가했고(현재 소속팀 포함), `clubs` 테이블에 유럽 5대 리그 전체 96개 구단을
